Capabilities

Everything runs on the box you already own.

One FastAPI process holds the collector, analyzer, playbook registry, safety guard, executor, incident manager, audit journal, and dashboard.

01

Native metrics

Load, memory, disk, and service state read straight from Linux tools and /proc — no agent or exporter to maintain.

02

Local analysis

A compact snapshot goes to Ollama over the OpenAI-compatible API and returns strict JSON: issue, severity, playbook, verifier.

03

Governed playbooks

Bundled playbooks ship read-only. Custom playbooks you author create immutable revisions, so every run is traceable.

04

Safety guard

A denylist blocks dangerous patterns, timeouts are capped, and each playbook's risk tier decides auto-run versus confirmation.

05

Verifier + recheck

Remediation is confirmed by a verifier script exiting 0 and a metric recheck. Unresolved incidents get one recommendation-only follow-up.

06

Permanent record

State lives in SQLite; every action is appended to a JSONL audit journal you can ship, hash, or grep forever.

How it works

Collect, analyze, guard, verify.

1

Collect

Every 30 seconds a snapshot is taken from the host.

2

Analyze

Ollama returns a strict JSON verdict with a playbook and verifier id.

3

Guard

The safety guard checks the denylist, timeout, and risk tier before anything runs.

4

Verify

Verifier exit 0 plus a metric recheck resolves the incident; the rest is audited.

Safety first

Remediation that can say no.

OpsPilot never improvises a command. Only the playbook catalog can run, and the safety guard sits between the decision and the shell.

  • Denylist blocks destructive command patterns before execution.
  • Per-playbook risk tier chooses auto or confirm.
  • Command timeouts are enforced and capped.
  • Bundled playbooks are read-only; custom edits become new revisions.
  • No playbook match means no execution — it becomes a recommendation.
# playbook: opspilot/playbooks/builtin
id: sample-noop
title: Sample read-only playbook
description: Demonstration playbook that reads system state.
risk: auto
auto_run: true
steps:
  - id: load
    command: uptime && free -b
verifier_id: sample-verify

YAML playbooks. Read-only bundled set, mutable custom set with immutable revisions.

Quick start

Up in four commands.

$ python -m venv .venv && . .venv/bin/activate
$ pip install -e .
$ export OPSPILOT_DATA_DIR=/var/lib/opspilot
$ export OPSPILOT_ADMIN_PASSWORD='change-me'
$ opspilot --config-check && opspilot

Open http://127.0.0.1:8443/. Leave OPSPILOT_ADMIN_PASSWORD empty for read-only web mode. Full options are in the configuration reference.

Read the docs, then point it at a host.
